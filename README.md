# DeskMonitor — Компактная панель мониторинга для Windows

Лёгкая, быстрая и компактная панель мониторинга рабочего стола Windows (CPU, Cores, GPU, RAM, Ping, Сетевой трафик и IP-адреса). Создано AI.

## Возможности и особенности

1. **Компактный адаптивный размер (от 140 пикселей в ширину)**:
   - Минимальная ширина снижена до **140 px** — панель занимает минимум места на экране.
   - Надписи и значения адаптивно форматируются под ширину (не ломаются, не наезжают друг на друга и не обрезаются).
   - Пользователь может свободно расширять окно на любую нужную ширину, потянув за край.

2. **Шкалы ядер процессора в один столбец**:
   - Полоски каждого ядра процессора выстроены **в один столбец, друг над другом**.
   - Номера ядер начинаются с `1` (1, 2, ... N).
   - Максимально тонкие и компактные (высота 3 px, шаг 8 px), отлично читаются даже при ширине 140 px.

3. **Шкала загрузки видеокарты (GPU Load)**:
   - Отдельная шкала и процент текущей загрузки видеокарты.
   - Сбор метрик осуществляется через системный Performance Data Helper (`pdh.dll`) по 3D-движкам видеокарты.

4. **Текущий пинг в правом верхнем углу над графиком**:
   - Вместо служебных надписей в правом углу над каждым графиком отображается точный **текущий пинг в миллисекундах** (`14 ms`, `Таймаут` или `— ms`).
   - Слева отображается имя целевого хоста (`8.8.8.8`, `1.1.1.1` и др.).

5. **Авто-масштабируемый график сетевого трафика (Download / Upload)**:
   - Расположен непосредственно **над разделом IP-адресов**.
   - Отображает текущую скорость загрузки (`↓`) и отдачи (`↑`).
   - Автоматически масштабирует максимальную шкалу графика под текущий поток данных (`[1.5M]`, `[500K]` и т.д.), благодаря чему хорошо видны как небольшие объёмы трафика, так и пиковые нагрузки.

6. **Нижний блок с IP-адресами**:
   - Всегда зафиксирован в самом низу окна.
   - При ширине до 180 px отображается в 2 аккуратные строки (`L: ...`, `E: ...`), при большей ширине — в одну строку.
   - Кнопка ручного обновления `⟳` (адреса опрашиваются при запуске и по кнопке, не создавая лишней нагрузки на сеть).

7. **Цветовая схема**:
   - Настройка индивидуальных цветов для CPU, GPU, RAM, Ping, Сети (Загрузка ↓ и Отдача ↑) и текста.
   
8. **Анализ топ-процессов по загрузке CPU (значок молнии ⚡)**:
   - Маленький значок молнии ⚡ рядом с надписью `CPU`.
   - При клике открывает компактное стильное окно со списком процессов, создавших наибольшую нагрузку на процессор за выбранный период (по умолчанию 10 минут).
   - Отображает имя процесса, шкалу использования, процент загрузки и суммарное время работы на CPU.
   - Возможность отслеживать как активные, так и завершившиеся тяжелые процессы (сборки, рендеры и т.д.).
   - Полная настройка параметров в отдельной вкладке: количество процессов (3–15), период анализа (1–60 мин), частота опроса (1–10 сек) и отключение значка при необходимости.
   - Энергоэффективный сбор телеметрии в пуле потоков без блокировки интерфейса и без микростаттеров (<0.02% CPU).

## Структура файлов проекта

| Файл | Описание |
|---|---|
| `DeskMonitor.exe` | Исполняемый файл приложения с иконкой и манифестом |
| `Program.cs` | Точка входа, Single Instance Mutex |
| `MainForm.cs` | Главное окно, адаптивная отрисовка от 140px, шкалы ядер, значок ⚡, GPU, пинг, трафик сети и IP |
| `TopProcessesForm.cs` | Всплывающее компактное окно топ-процессов по загрузке CPU |
| `ProcessCpuTracker.cs` | Фоновый энергоэффективный сборщик телеметрии нагрузки процессов на CPU |
| `GpuMonitor.cs` | Мониторинг 3D-нагрузки видеокарты через Win32 PDH API |
| `NetworkHelper.cs` | Асинхронный пинг, авто-масштабируемый трекер сетевого трафика и определение IP |
| `SystemMetrics.cs` | Мониторинг CPU (общего и по ядрам через PerformanceCounter), RAM и GPU |
| `SettingsForm.cs` | Диалоговое окно настроек с 4 вкладками (Общие, Цвета, Топ CPU ⚡, Пинг) |
| `AppSettings.cs` | Конфигурация, цвета, список хостов и сериализация `settings.json` |
| `AssemblyInfo.cs` | Метаданные сборки PE (версия 1.0.0.0, компания, продукт) |
| `app.manifest` | Манифест приложения Windows (`asInvoker`, DPI awareness) |
| `app.ico` | Встроенная многослойная иконка приложения |
| `build.bat` | Скрипт сборки через встроенный компилятор `csc.exe` |

## Сборка из исходников

Сборка выполняется встроенным в Windows компилятором C# без установки стороннего ПО:
```cmd
build.bat
```
